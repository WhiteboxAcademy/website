What “inference” means

Training makes the model.
Inference runs it.

NOT IN THIS COURSE

Training

Learns the model’s weights from huge amounts of text. Many GPUs, weeks of work, done once.

EVERY CHAPTER

Inference

Uses those weights. Your text goes in, a score for every next token comes out, one is picked, and it repeats. Every model call you’ve made was inference.

FAQ

Questions before you start

Is this about training a model?

No. You take a model that is already trained, Qwen2.5, and run it with your own code. Nothing in this course changes the weights.

Do I need a GPU?

No. Everything runs on your own computer with at least 8 GB of memory. The model is small, about half a billion numbers, so numpy can run it.

Do I need to finish Course 01 first?

Only its Part 1: your first model call, how LLMs work, and prompting. Those three chapters set up the words and ideas this course opens up.

Why numpy and not PyTorch?

So nothing is hidden. Every step is a plain array you can print, check and change, and the install stays small.

Will I build something like Ollama?

No. There’s no server or app. The goal is to understand what happens inside the model, and you use Ollama as the yardstick to check your own code against.

How much maths is there?

Only what explains something you just saw. You measure first, then the formula arrives, and it’s always written as numpy code too.
