Setup

Where we’re going

Build an agent from scratch

By the end of this course, you’ll have your own agent framework and a coding agent that fixes bugs on its own.

An AI model is a program that reads text and predicts a reply. An agent is a model that can also use tools to get work done. You’ll learn exactly how that works in later chapters. For now, you only need to get the tools installed.

ToolWhat it does
PythonRuns all the code in this course

Your questions stay on your computer, and you don’t need an account or API key yet.

Walkthrough

Six steps to a working setup

  1. Get the course. Open the course on GitHub, choose Code > Download ZIP, and unzip it somewhere easy to find.
  2. Install Python. Get Python 3.12 or newer from python.org. On Windows, tick Add python.exe to PATH on the first install screen, and use python instead of python3 throughout this course.
  3. Install Ollama. Get it from ollama.com/download.
  4. Start Ollama. Ollama is a small server that runs in the background, and it needs to be running whenever you use a model. Open the Ollama app and leave it running, or run ollama serve in a separate terminal and leave that terminal open. Then run ollama list to check. You’ll see a table of models, which may be empty. If you see could not connect to ollama server, it isn’t running. You may need to start it again after you restart your computer. On Linux, the installer usually starts it for you, so if ollama serve says the address is already in use, it’s already running.
  5. Download the model. Run ollama pull qwen2.5:7b in a terminal.
  6. Run the setup check. In the terminal, go to chapters/00-setup/code and run python3 check_setup.py.

Under 8 GB of memory?

Use qwen2.5:3b instead, and run python3 check_setup.py qwen2.5:3b. It’s enough to start, but in our test it got 0 of 5 runs right on the multi-step task in chapter 12. If you can, use a computer with at least 8 GB.

The setup check

You’re ready at 7/7

This is real output from a working setup. Your numbers will be different. The check asks the model two small questions, so it may take a minute.

7/7 passed

If a check fails

Each failure tells you what to do next. Fix the first FAIL line, then run the check again. SKIP means a check couldn’t run until that failure is fixed.

$ python3 check_setup.py
PASS  Python: 3.15.0
PASS  Disk space: 48 GB free
PASS  Memory: 24 GB
FAIL  Ollama: Ollama isn't running. Open the Ollama app, or run: ollama serve
SKIP  Model installed: fix the failure above first
SKIP  Model answers: fix the failure above first
SKIP  Model uses tools: fix the failure above first
3/7 passed
Your turn

Exercise

Run the setup check until you see 7/7 passed. Then talk to your model:

$ ollama run qwen2.5:7b "Explain what a terminal is in one sentence."

Your reply will be different each time, because models don’t always give the same answer. You’ve finished this chapter when you get a reply.
