Where we are

What an LLM is

In chapter 06, the same question gave different answers, and the model forgot your name. This chapter solves both puzzles. LLM stands for large language model. It’s a program trained on a huge amount of text to do one job: predict what comes next.

Inside is a very large set of numbers, called parameters. Your model has about 7.6 billion of them. They were set during training, and they don’t change when you use the model. Everything an LLM seems to do comes from that one job, repeated.

Walkthrough

Six experiments

Before each one, predict what will happen. A wrong guess is often the most useful result.

  1. Tokens

    Models read tokens, which are small chunks of text. For English, a rough rule of thumb is 4 characters per token. Other languages often take more. Limits are measured in tokens, and cloud models usually charge by the token.

  2. Next-token prediction

    The model gives every possible next token a chance, picks one, adds it to the text and repeats. Here, the blanks probably reflect fill-in-the-blank text it saw in training. Either way, it’s predicting likely text, not looking up a fact.

  3. Temperature

    Temperature controls how the model picks. At 0, it always takes the top choice. Higher values add variety. That solves puzzle 1: the default temperature isn’t 0, so the same question gave different answers. Use a low temperature for reliable tool use. Even at 0, results can differ between machines and model versions.

  4. No memory

    Each call starts from nothing. That solves puzzle 2: your second call didn’t include your name. When a chatbot seems to remember you, the app is resending the conversation. You’ll write that code yourself in chapter 12.

  5. Context window

    The context window is the most tokens a model can handle at once, including its reply. With a small window, the secret code was lost and the reply was nonsense. There was no error message, because Ollama cut the text and carried on.

  6. Made-up answers

    We asked for a summary of a paper that doesn’t exist, and the model gave one confidently. This is called hallucination. It did refuse two other made-up questions, so you can’t predict when it will happen. That’s a big reason why agents use tools.

Exercises

Open exercises.py and complete the five TODOs:

  1. estimate_tokens: use the rule of thumb.
  2. most_likely: pick the top token.
  3. apply_temperature: see how temperature changes the chances.
  4. fits_window: check a context limit.
  5. add_turn: add to a conversation without changing the original.

Then run python3 -m pytest test_exercises.py. You’ve finished when you see 5 passed.

Common mistakes

  • Thinking the model looks facts up. It predicts text.
  • Thinking the model remembers earlier calls. Your code has to resend them.
  • Counting words instead of tokens.
  • Expecting an error when the context overflows. You may just get a bad answer.
Recap

What you opened

  • An LLM predicts the next token, one at a time.
  • Tokens are the chunks of text a model reads.
  • Temperature controls how much variety you get.
  • Each call starts with no memory.
  • The context window limits what fits, and overflow can be silent.
  • Models can state made-up things confidently.
