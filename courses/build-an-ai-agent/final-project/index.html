How your idea is picked

Your name, the second you rolled and both dice go through SHA-256. The first four bytes pick an idea from your level. Every second gives a different roll, and the result shows its time, so anyone can see the same roll again and check it.

The same sum runs in roll.py in the course code, so you can check any roll on your own machine. Nothing on this page is sent anywhere.

      THE RULES
      
      
        
    • A weekend’s work. Small and finished beats big and half-done.
      • 
        
    • Works on qwen2.5:7b, so anyone can run it for free. A cloud model is fine as well.
      • 
        
    • Free: no paid service and no sign-up.
      • 
        
    • No one else’s personal data. Use your own, or make some up.
      • 
        
    • Any framework from the course: whitebox, LangGraph or Pydantic AI.
