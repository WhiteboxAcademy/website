FAQ

Questions before you start

Do I need a paid API key?

Not to get started. The course runs a model on your own computer with Ollama, so you need at least 8 GB of memory and about 10 GB of free disk space. A Gemini API key comes in at chapter 31, when you learn to switch models.

I already know Python. Can I skip ahead?

Yes. Part 0 covers everything you need from Python, with a way to skip it if you already know it.

How long does it take?

About 85 hours across 35 chapters. It’s fully self-paced, so you choose how fast to go.

Do I need to know Git?

No. You can download the course code from GitHub as a ZIP file, and you don’t need a GitHub account.

What are the videos like?

They’re silent, with captions on screen, and each one opens with a 30-second recap.

Can I reuse the material?

Yes. The code is under the MIT License, and the articles and videos are under CC BY 4.0, so you can reuse them with credit.
