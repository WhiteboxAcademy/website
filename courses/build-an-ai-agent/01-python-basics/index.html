Walkthrough

The four building blocks

  1. Values and variables

    A variable is a name for a value, and = stores it. Each value has a type: str for text, int for whole numbers, float for decimals and bool for true or false. An f-string such as f"Cost: {total}" puts values inside text.

  2. Decisions and loops

    if runs code only when a condition is true, and the four spaces of indentation show which lines belong to it. for repeats for each value, and while repeats while a condition is true. range(1, 4) gives 1, 2 and 3, because it stops before the second number.

  3. Functions

    A function is a named block of code you can reuse. Parameters are its inputs, and return sends a result back. An agent’s tools will be ordinary functions just like these.

Reading errors

Errors are normal

Python tells you what went wrong. Read the last line first, then the line it points to. These are real error messages:

What you didWhat Python saysThe fix
Mixed text and a numberTypeError: can only concatenate str (not "int") to strUse an f-string
Forgot to indentIndentationError: expected an indented block after 'if' statement on line 2Add four spaces
Misspelled a nameNameError: name 'prise' is not defined. Did you mean: 'price'?Correct the spelling
Used print instead of returnTypeError: unsupported operand type(s) for +: 'NoneType' and 'int'Use return

A function without return gives back None, which means “no value”.

Common mistakes

  • Using = when you mean ==. One stores a value, and the other compares.
  • Forgetting the : at the end of if, for, while or def.
  • Using print in a function when you need return.
  • Expecting range(1, 4) to include 4.
